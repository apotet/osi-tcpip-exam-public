Шаг сети станет очевидным

Сначала запомни восемь весов бита, затем маски. Для любой непривычной маски используй одно правило.

Шаг = 256 − октет маски.
Например, /27 → 255.255.255.224 → 256 − 224 = 32. Сети: 0, 32, 64, 96…

1. Пойми один октет

Нажми на последний сетевой бит: слева автоматически будут только единицы, справа — только нули.

Полная таблица /0–/32. В заданиях используются /8–/30. Шаг указан вместе с номером октета: /23 → 2 в третьем, /22 → 4, /21 → 8. Например, соседние /23: 192.168.0.0, 192.168.2.0, 192.168.4.0. При переходе к следующему блоку младшие октеты обнуляются.

Для /0–/30 показан обычный расчёт 2^(32−префикс)−2; это арифметическая ёмкость, не число публично доступных адресов. /0 охватывает всё пространство IPv4, соседнего блока нет. * /31 и /32 — особые случаи: /31 применяется на point-to-point без обычных network/broadcast, /32 обозначает один адрес.
