Отправь ping на сервер

Доставь ping от ПК к серверу

Условия и границы модели

ПК 192.168.1.10/24 → коммутатор → маршрутизатор LAN 192.168.1.1/24, WAN 192.168.2.1/24 → сервер 192.168.2.20/24. Маска /24 = 255.255.255.0.

ПК: default через 192.168.1.1. Сервер: обратный default через 192.168.2.1. На маршрутизаторе connected 192.168.1.0/24 и 192.168.2.0/24. IP forwarding включён; NAT и proxy ARP выключены.

Начало: все ARP-кэши и MAC-таблица коммутатора пусты. Одна VLAN в LAN; коммутатор учит source MAC и передаёт broadcast всем LAN-портам, unicast по изученному порту. MAC сервера находится в другом L2-сегменте.

Один ICMP Echo Request/Reply, id 42, sequence 1. Начальный TTL каждого нового IP-пакета 64. Линки исправны, ICMP разрешён; без потерь, ACL, VLAN-тегов, таймеров и фонового трафика. ARP изучается из запроса и ответа, записи не стареют. Это ограниченная учебная модель, не сетевой эмулятор. Checksum показана символически, не побайтно.
