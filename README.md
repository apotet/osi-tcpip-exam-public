# Network Engineer Trainer

Практический тренажёр для изучения сетей: OSI/TCP/IP, IPv4/IPv6, CLI и диагностика.

## Что внутри

- экзамен из 502 вопросов;
- L1-вопросы по реальным фотографиям оптики, SFP и сетевого оборудования;
- обучение по уровням OSI;
- IPv4-тренажёр с масками, подсетями, broadcast и VLSM;
- IPv6-тренажёр;
- CLI-справочник и практика для Cisco, Eltex, H3C, MikroTik, Siemens SCALANCE и Huawei;
- практические сценарии диагностики.

## Лицензии

Код проекта распространяется по лицензии MIT. Оригинальные вопросы, объяснения и учебные тексты — по CC BY-SA 4.0. Подробности: `LICENSE` и `CONTENT_LICENSE.md`.

Фотографии L1 взяты из Wikimedia Commons и остаются под лицензиями их авторов. Источники и лицензии указаны в интерфейсе сайта и сопутствующих данных проекта.

## Технологии

Проект намеренно остаётся лёгким: HTML, CSS и JavaScript без тяжёлого frontend-фреймворка. Автотесты и проверки запускаются через GitHub Actions.

## Статус

Проект активно развивается. Перед крупными изменениями приоритет — корректность вопросов, мобильная версия и практическая полезность для сетевого инженера.
