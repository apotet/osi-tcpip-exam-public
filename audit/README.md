# Воспроизводимый аудит Этапа 1

Требуются Node.js 20+ и Python 3. Из корня репозитория:

```sh
npm ci
npx playwright install --with-deps chromium firefox webkit
npm test
```

`npm run audit:static` проверяет банк, семьи вопросов, ссылки на подробные
пояснения, реальные функции IPv4, VLSM, размеры и SHA-256 ресурсов.
`npm run audit:browser` запускает 135 сценариев: три движка × пять viewport
(360, 390, 430, 768, 1440 px) × девять сценариев.
Playwright сам запускает локальный HTTP-сервер на 127.0.0.1:4173.

Проверяются все пять HTML-страниц, внутренние href/src и fragment ID,
reload/Back/Forward, console.error, pageerror, HTTP 4xx/5xx и ошибки запросов,
горизонтальный overflow, экзамен OSI, учебные карточки и диалоги,
все режимы IPv4/IPv6 до завершения попытки, карточки всех CLI-вендоров,
поиск, фильтры и экраны сценариев. Учебные и CLI-карточки раскрываются
через нативное свойство `details.open`; кнопки пояснений и диалогов проверяются
реальными кликами. Это эмуляция viewport и touch, а не
проверка физических iPhone/Android. WebKit на Linux не равнозначен Safari на iOS.

Для замера начальной загрузки запустите сервер, затем:

```sh
python3 -m http.server 4173 --bind 127.0.0.1
# В другом терминале:
npm run audit:resources
npm run audit:links
npm run audit:icons
```

JSON-результаты находятся в `audit/results/`, скриншоты и failure traces —
в `test-results/`. `audit:links` дополнительно собирает ссылки из динамических
CLI-карточек всех вендоров, сценариев и всех фото банка, затем проверяет HTTP
и fragment ID с дедупликацией запросов. Эти каталоги исключены из git. Начальная загрузка измеряется
в новом контексте Chromium на 390 px без сжатия, на localhost; время не является
оценкой скорости GitHub Pages или мобильного соединения.

В ограниченном окружении можно указать `AUDIT_WEBKIT_EXECUTABLE` для отдельной
копии WebKit. Для запуска 2026-10-04 библиотеки Debian были распакованы в `/tmp`,
а wrapper копии WebKit изменён для сохранения `LD_LIBRARY_PATH`. Штатная установка
Playwright не менялась. `PLAYWRIGHT_SKIP_VALIDATE_HOST_REQUIREMENTS=1` использован,
поскольку проверка dlopen через системный ldconfig не видит библиотеки в `/tmp`.
Сам движок обязан успешно запуститься; отсутствие библиотек не считается проходом.

Базовая проверка банка не доказывает техническую корректность всех ответов и
дистракторов. Поиск мёртвых функций по числу вхождений — эвристика; экспортированные
API и динамические вызовы требуют ручной проверки. Полная редактура банка,
CLI на оборудовании и публичная доступность без VPN остаются отдельными задачами.
