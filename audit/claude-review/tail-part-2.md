## review-prp-12

2. Один активный и один STP-путь
3. Один IP через два VRRP-шлюза
4. Потоки по хэшу членов LACP

Правильные по текущему ключу: 1.

Пояснение: PRP отправляет две копии одного кадра одновременно через независимые сети LAN A и LAN B. Получатель использует первую пришедшую копию, а повторную отбрасывает. Поэтому отказ одной сети не требует ждать переключения обычного трафика.

Что означает контрольная точка в сеансовом обмене?

1. Точку согласованного восстановления
2. Номер подтверждённого TCP-байта
3. Адрес промежуточного IP-шлюза
4. Порт резервного Ethernet-пути

Правильные по текущему ключу: 1.

Пояснение: Контрольная точка — согласованное место в обмене, с которого стороны могут продолжить работу после сбоя, если протокол это поддерживает. Пример: возобновить большую передачу с подтверждённого этапа.

Почему трудно выделить отдельный L5-модуль в обычном TCP/IP-приложении?

1. Функции объединены приложением
2. Все функции заменены Ethernet

4. Функции вынесены в IP-шлюз

1. Согласования представления
2. Согласования IP-префикса
3. Согласования Ethernet MTU
4. Согласования TCP-порта

Устройства одинаково доставляют байты, но одно неверно читает UTF-8. Где искать причину?

1. Кодировка и декодирование
2. Маршрут и next hop
3. VLAN и обучение MAC
4. Speed и duplex порта
