# First steps: восемь кадров

Автор: проект Network Engineer Trainer (apotet/osi-tcpip-exam), 2026-10-24.
Происхождение: собственный детерминированный синтетический трафик; сторонних трасс, пользовательских захватов и производственных данных нет. Пакеты не отправлялись в сеть. Генератор Python 3 stdlib: `scripts/generate-wireshark-basics.py` в исходном приватном репозитории. Случайность не используется. Фиксированное время в pcap: 2026-01-01 00:00:00 UTC, не дата реального захвата.

Точка условного захвата — Ethernet-интерфейс A, вход/выход, полные кадры без FCS. A = 192.0.2.10/24 / 02:00:00:00:00:10, B = 192.0.2.20/24 / 02:00:00:00:00:20, C = 192.0.2.30/24 / 02:00:00:00:00:30. Все находятся на одном L2-сегменте. В начале у A нет ARP-записей B и C. B/C изучают A из его запросов; дополнительных запросов им не требуется. Никакого маршрутизатора, proxy ARP или скрытых потерь.

Порядок: 1/2 — ARP A↔B, 3/4 — Echo A↔B, 5/6 — ARP A↔C, 7/8 — Echo A↔C. По одному ping к каждому соседу. Данные Echo в обе стороны одинаковы: ASCII `Stage7 echo sample`, 18 байт. Identifier (BE) = 4660 для B, 22136 для C; Sequence (BE) = 1. Все кадры — 60 байт, ARP дополнен нулевым Ethernet padding до минимальной длины. IPv4 Total Length = 46, ICMP = 26 байт; Ethernet padding у ICMP отсутствует. Преамбула, FCS и межкадровый интервал не записаны. ARP не содержит checksum; IPv4 и ICMP checksum проверены tshark. Отсутствие FCS не означает ошибку.

Открыть `first-steps.pcap` в Wireshark через File → Open; убрать display filter, сортировать по No., выбрать Seconds Since Beginning of Capture. Поля — в Ethernet II / ARP / IPv4 / ICMP. Для сопоставления Echo использовать адреса в обратных направлениях, Type 8→0, Identifier (BE) и Sequence (BE). Настоящий захват не нужен.

Ограничения: идеализированный короткий обмен, тестовые IPv4 из RFC 5737 и локально администрируемые MAC. Не модель реальной производительности/оборудования. Ответ Echo не доказывает доступность приложений. Никаких фильтров, TCP/DNS или диагностики пакетов 2–5.

`first-steps-data.js` извлечён из самого pcap независимым tshark 4.4.18 (`-n`, `ip.check_checksum:TRUE`), а не из внутренних объектов генератора. `manifest.json` содержит hash, точку наблюдения и ограничения. Версия проверки относится к инструменту, а не гарантирует идентичность UI всех выпусков Wireshark.
