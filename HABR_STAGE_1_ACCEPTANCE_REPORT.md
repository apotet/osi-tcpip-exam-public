## Ограничения и остаточные риски

- Контрольный банк подставляется только в тестовом контексте. Он доказывает
  механизм grading, но не предметную корректность настоящих `correct`/дистракторов.
  Перехват не меняет опубликованный банк. Реальный банк проверяется структурно.
- Linux WebKit и эмуляция touch/viewport не равнозначны реальным Safari/iOS/Android.
  Массовое раскрытие learning/CLI через `details.open` проверяет DOM и ресурсы,
  но не доказывает удобство нажатия всех summary пальцем и keyboard/focus.
  Favicon audit проверяет декларацию и SVG/HTTP, не значок нативной вкладки headless-браузера.
- Проверяются текущие внутренние ссылки и статические fragment IDs, ресурсы
  динамических CLI-состояний и фото банка. Внешние источники и будущие ссылки,
  отказ сети/offline, file://, публичный base path этим прогоном не покрыты.
- Ресурсы измерены на localhost без сжатия, без сетевого throttling. Это объём
  загрузки, не доказательство приемлемой скорости реального хостинга.
- IPv4 генератор ограничен /8–/30; /31,/32 — табличные special cases. IPv6 oracle
  покрывает hex/colon грамматику; две из 13 отклоняемых форм — валидные IPv4-embedded
  и zone-ID формы вне поддержки тренажёра. prefix64 проверяется на валидном входе.
  Терминология и прочие IPv6 факты требуют редактора.
- Dead code проверяется эвристически по вхождениям; динамические вызовы/экспорты
  не доказаны полной coverage. Произвольные схемы повреждённого storage не исчерпаны.
- WebKit запущен с временными библиотеками в /tmp и wrapper; штатная проверка
  host requirements отключена, реальные тесты движка выполнены. CI workflow и
  постоянное хранение raw artifacts в удалённом CI не добавлялись.

Наблюдённый **P2**: OSI принимает из localStorage finite score вне 0–10.
Штатный экзамен таких значений не создаёт, но повреждённая история может показать
невозможный балл. Не исправлялся по заданию: [backlog](audit/STAGE_1_BACKLOG.md).
Спорные пары и весь предметный review — [отдельный список](audit/CONTENT_REVIEW_LIST.md).
Это остаточные риски перед merge; отсутствие конфликта не означает разрешение merge.
